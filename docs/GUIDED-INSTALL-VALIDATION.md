# Guided install validation — 23 October 2026

The root Windows/Linux installers add missing-prerequisite planning/consent and a shared private dashboard lifecycle. Existing application modules remain. This release does not change the existing production dashboard or phones.

Both Windows and Linux ran a real local backend/dashboard through the new background supervisor using isolated test state, precreated throwaway authentication and guards that block phone commands and non-loopback/provider traffic. Eleven checks passed per platform: occupied-port preservation, correct ready URL, actual HTML serving, remote password gate, invalid supervisor token rejection, continued service after invalid Stop, same-instance reuse, status, Stop, supervisor disappearance and preservation of the unrelated listener. The final launcher uses instance-tagged readiness, a checkout lifetime/install lock, a Windows kill-on-close child Job Object, and POSIX child-group termination.

The guided/portable gate passed 27 tests per platform. Setup unit tests cover dry-run nonmutation, invalid ports, fallback without takeover, rejection of wrong-checkout/control identity, no URL on failed readiness, and exclusion of unrelated shell credentials. Additional source contracts check entry points/docs, npm.cmd, explicit consent/scope and verified Linux Node downloads. Portable origin/state/privacy/release-guard tests are retained. Windows PowerShell and Linux Bash syntax/dry-runs passed without OS changes. Missing-tool plans were inspected on the current machines; actual apt/dnf/WinGet installations and UAC/reboot cycles were deliberately not run on the user's development computer. Therefore fresh-machine package installation is implemented and syntax/plan-tested, not claimed physically completed on every clean Windows/Linux image.

Existing regression evidence remains in PORTABLE-RELEASE-VALIDATION.md: 54 isolated customized backend suites per platform, 419 reported cases including 7 explicit skips per platform, a separate 6-case SDK adapter gate, and all 32 frontend regression suites. The final guided work changes installer/launcher code, not native controls, streaming, groups, proxies, AI job policy or device commands. The 32 frontend suites were rerun for this release; no functionality was removed to simplify installation.

The security review identified concrete prerequisites/lifecycle defects before publication. Corrections include Windows npm.cmd detection, truthful package scopes, a nonblocking -Yes path, Linux system-Node/ensurepip checks, ASCII-safe authentication success output, instance-bound health checks, private process ownership, a foreground/install lock and a filtered long-lived environment. An older/unmanaged existing environment additionally requires an owner confirmation that its services have stopped before update. No PID from disk is used as kill authority.

The default setup remains local-only and does not silently install login/reboot startup, root AI services, WSL, a public gateway or firewall rules. WinGet/App Installer, supported distro repositories, internet, software licenses and elevation may require the owner's action. Full Fleet AI isolation, API keys/local models/proxies, phone debugging/pairing and optional iOS/Portal integrations require their documented separate configuration. Gmail/account/OTP/CAPTCHA/terms decisions are not made unattended.

Public-source export excludes all test/production state, dependency folders, logs, private keys, credentials, generated builds and launcher locks. A new history is used for the requested public repository; previous private-repository history and machine deployment files are not imported. The source guard and exact per-file hashes are checked before upload and a fresh remote clone is used to verify publication. Publication status/commit are reported by the release task after GitHub confirms them, not guessed here.

Before public upload, an independent Gitleaks v8.30.1 scan reported zero findings after synthetic fixtures were made unambiguous and an optional example API key was left blank. The 12 affected backend fixture tests and all 32 frontend suites passed again. No scan paths were excluded to hide findings.
